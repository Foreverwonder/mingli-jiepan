# Mingli Jiepan — 四流派命理解盘 Skill

> 一个命盘，四个流派独立分析，交叉验证，给出汇总结论。

规定大模型如何对一个命盘依次进行 **八字、紫微斗数、奇门遁甲、六爻** 四个流派的独立分析，最后做四流派交叉验证并给出汇总结论。用于批量、规范、可复用地对每个家庭成员命盘做深度解盘。

## 为什么做这个

单一流派看命盘容易"各说各话"，四个流派对同一命盘交叉验证，能显著提高解盘的稳定性和可信度。这套方法论把"如何规范地让 AI 做多流派分析"完整流程化——是 Agent 在垂直领域做**多模型交叉验证**的参考实现。

## 工作流程

```
输入出生时间
  → 八字独立分析（十神/格局/大运/喜忌）
  → 紫微斗数独立分析（十二宫/四化/三方四正）
  → 奇门遁甲独立分析（用神落宫/格局吉凶）
  → 六爻独立分析（卦象/用神旺衰）
  → 四流派交叉验证（一致点 / 分歧点）
  → 汇总结论（分层叙事输出）
```
